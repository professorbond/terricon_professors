# JanaМен · бэкенд

HR-платформа для Jana Post (хакатон Terricon Valley, кейс Digital HR). Стек: FastAPI, SQLAlchemy 2 (async), PostgreSQL 16, Alembic, Python 3.12, [uv](https://docs.astral.sh/uv/).

## Запуск

```sh
# из корня репозитория — всё сразу: Postgres, API, фронтенд
docker compose up
#   фронтенд  http://localhost:5173
#   API       http://localhost:8000/docs   (Swagger)

# или локально
cd backend
uv sync
docker compose up -d db
uv run uvicorn app.main:app --reload
```

При старте применяются миграции и seed с вымышленными данными. Если seed изменился, демо-данные пересоздаются сами.
Вручную данные сбрасываются через `POST /api/demo/reset`. Ключ Claude (`ANTHROPIC_API_KEY` в `.env`) необязателен: без него AI Jana отвечает фрагментом базы знаний.

## Проверки

```sh
cd backend
uv run pytest -q                     # 128 тестов (SQLite в памяти)
uv run python scripts/smoke_api.py   # 108 сквозных проверок живого API на Postgres (роли, права, гонки)
uv run python scripts/demo_check.py  # демо-сценарий CLAUDE.md §12 по шагам
```

Оба скрипта делают `POST /api/demo/reset`, то есть стирают демо-данные.

## Демо-сценарий (CLAUDE.md §12)

1. **Айгерим** входит. На главной видно «Мои гарантии», «Доступно 84 000 ₸», «Ответ по отпуску до …». В профиле: «Лестница: осталось 1 курс, +35 000 ₸».
2. «Зарплата по факту» на 60 000 ₸: заявка одобрена системой, документ оформлен в Documentolog, выплата прошла, пришло уведомление.
3. **Ерлан** пытается отклонить отпуск без причины и получает `REASON_REQUIRED`. Профиль сотрудника смены А возвращает 403.
4. Демо «+2 дня»: отпуск одобрен по сроку, автор получил уведомление.
5. Айгерим проходит курс «Техника безопасности»: лестница показывает «все условия выполнены».
6. AI Jana:
   - вопрос про отпуск получает ответ с источником ТК РК;
   - тот же вопрос от Бакыта — ответ с источником ТК КР;
   - «зарплата начальника» — отказ;
   - «ночные смены» — «нет информации» и кнопка «Спросить HR».
7. **Данияр** (HR) открывает радар: у Айгерим `no_review` и `pay_equity`, у Нурлана `rejections`, `slow_answers` и `open_grievance`. «Предложить пересмотр» отправляет уведомление и ставит новую дату в лестнице. «Сотрудник остался» меняет счётчик с 9,9 до 10,8 млн ₸.
8. Рентген показывает Ерлана наверху. Пробелы базы: «23 вопроса про ночные смены» → черновик → публикация → AI отвечает по «Внутреннему правилу».
9. Биржа смен: Айгерим отдаёт смену, Асель берёт её в одно нажатие и видит «+12 000 ₸».

## Флаги ext-фич

`EXT_FEATURES` в `.env`: `*` включает все фичи, `""` — ни одной, можно перечислить через запятую.

| Флаг | Фича |
|---|---|
| `guarantees` | Гарантии и политики |
| `wage_access` | «Зарплата по факту» |
| `hr_console` | Радар и счётчик |
| `ladder` | «Открытая лестница» |
| `grievance` | «Обращение» |
| `xray` | Рентген руководителей |
| `kb_gaps` | Пробелы базы знаний |
| `shifts` | Биржа смен |

Обязательная часть кейса от флагов не зависит.
`GUARANTEES_REQUIRE_REASON=false` временно разрешает отказ без кода причины (подставляется `OTHER`), пока во фронтенде нет выбора причины.

## Структура

```
app/
  main.py            # сборка: каркас + модули из modules/__init__.py (ext — по флагам)
  core/              # каркас: config, db, clock, auth, rbac, errors, events, ticks, i18n, профиль, модули
    org/             # страны, подразделения, сотрудники
    requests/        # движок заявок: типы, статусы, история, права, расширения карточки
    notifications/   # уведомления (ключи i18n + готовый текст)
    demo/            # перевод времени, сброс, вход за персонажа
  integrations/      # zup (1С, только чтение) · documentolog · bank · llm (Claude)
  modules/
    profile/ leave/ hr_question/ academy/ ai_jana/       # обязательная часть кейса
    ext_guarantees/ ext_wage/ ext_hr_console/ ext_ladder/
    ext_grievance/ ext_xray/ ext_kb_gaps/ ext_shifts/    # ext-фичи (флаги)
  seed/              # вымышленные данные (JSON, база знаний markdown KZ/KG)
alembic/versions/    # 0001…0010, одна голова
scripts/             # smoke_api.py, demo_check.py
tests/
```
