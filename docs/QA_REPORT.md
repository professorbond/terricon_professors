## Что проверено

### А1. Чистый запуск
- `docker compose down -v && up`: API отвечает через **5 с**, фронтенд через **37 с** (из них `npm ci` в контейнере ~30 с).
- Миграции 0001–0010 и seed применяются сами. Все контейнеры здоровы: у бэкенда добавлен healthcheck, фронтенд ждёт здоровый бэкенд.

### А2. Проход за каждого персонажа и форма ответов
`tests/test_qa_contract.py`. За всех 8 персонажей поля ответов сверены с типами фронтенда напарника.
Поля берутся **прямо из его TS-файлов** (`src/features/*/model.ts`), поэтому тест упадёт, если фронт поменяется.
Проверены `User`, `EmployeeProfile`, `LeaveRequest` и `LeaveRequestEvent`, `Notification`, `CourseSummary` и `CourseProgress`, `KnowledgeSource`.
Даты отдаются в ISO, время с зоной, деньги целыми числами. `Page<T> = {items, nextCursor: null}`.

### А5. Демо-режим
- **Перевод времени** влияет на сроки гарантий (автоодобрение, передача HR, просрочка вопросов к HR), месяц и лимит выводов, «смена в прошлом», сигналы радара (тик).
- **Сброс** повторяется 3 раза подряд без ошибок.
- При `DEMO_MODE=false` эндпоинтов `/api/demo/*` нет.

### А6. Безопасность
- **Секреты.** В репозитории и во **всей истории** (39 коммитов) нет ключей API, токенов, приватных ключей и `.env`; есть только демо-пароль `demo1234`.
- **Пароли** хранятся как PBKDF2-SHA256 с солью.
- **JWT.** Срок жизни 12 ч. Просроченный токен и токен с `alg: none` получают 401.
- **Ошибки.** Непредвиденная ошибка отдаёт 500 без стектрейса и без текста исключения.
- **Ввод.** Фильтры и пути выдерживают SQL-подобный ввод, спецсимволы, эмодзи и строки по 300 символов: ответ 200 с пустым списком или 422, данные целы.
- **CORS** разрешён только для `localhost:5173` и `:4173`, чужой origin не получает заголовков.

## Что осталось и известные ограничения

- **`target: null` у уведомлений** «пересмотр зарплаты» и «смены». Подходящего вида цели в типе фронтенда нет. Это расхождение №12 в `API_CONTRACT.md`: фронту нужно сделать `target` необязательным. Касается только ext-фич.
- **JWT-секрет по умолчанию** — дев-значение из кода. Для любого запуска вне демо задать `JWT_SECRET` в `.env`.
- **Живой вызов Claude не проверялся** (нет ключа). Путь с LLM покрыт тестами с подменой модели.
- **Тесты на SQLite** не проверяют блокировки строк. Гонки проверяются только в `smoke_api.py` на Postgres, его нужно запускать перед демо.
- **Казахский без LLM** работает по словарю ключевых слов, то есть для типовых тем. С LLM — полноценно.
