Набор проверяется автоматически: `backend/tests/test_ai_test_set.py` читает таблицу ниже.
Колонка «Ожидание»:
- `answer` — ответ с источником, `articleId` которого начинается с указанного значения;
- `refuse_other` — отказ без поиска: вопрос о чужих данных, `escalateAvailable: false`;
- `own` — ответ из «Данных 1С:ЗУП» текущего пользователя;
- `no_answer` — честный отказ и `escalateAvailable: true`.

Режим без LLM (экстрактивный). С ключом `ANTHROPIC_API_KEY` поиск и защита те же, меняется только формулировка ответа.
