# Кто чем владеет

Каждый правит свои модули. Изменения каркаса (`backend/app/core/`) после этапа 0 идут
отдельным PR с описанием, что меняется для другого.

| Область | Владелец | Папки |
|---|---|---|
| Фронтенд: оболочка, дизайн-система, профиль, отпуск, «Мои заявки», уведомления, Academy UI | Напарник | `src/`, `docs/DESIGN_SYSTEM.md`, `docs/SCREEN_MAP.md` |
| Бэкенд-каркас: конфиг, БД, авторизация, роли, оргструктура, движок заявок, уведомления, демо, интеграции | Даниил | `backend/app/core/`, `backend/app/integrations/`, `backend/app/seed/` |
| Модуль «Отпуск» (бэкенд) | Даниил сделал как эталон, дальше по договорённости | `backend/app/modules/leave/` |
| Academy (бэкенд) | Договориться | `backend/app/modules/academy/` |
| AI Jana | Даниил | `backend/app/modules/ai_jana/` + экран во фронте по договорённости |
| Гарантии, «Зарплата по факту», лестница, обращения, HR-пульт, биржа смен, рентген, пробелы базы | Даниил | `backend/app/modules/ext_*/`; экраны во фронте — договориться о папке (например `src/features/ext/*`) |

Общие файлы, куда можно только **добавлять строки**: `backend/app/modules/__init__.py` (список модулей),
`docker-compose.yml`, `.env.example`.
