# Кто чем владеет

Весь **бэкенд** делает Даниил, **фронтенд** — напарник. Граница между ними — HTTP API, описанный в
[`API_CONTRACT.md`](API_CONTRACT.md).

| Область | Владелец | Папки |
|---|---|---|
| Каркас бэкенда | Даниил | `backend/app/core/`, `backend/app/integrations/`, `backend/app/seed/` |
| Обязательные модули: профиль, отпуск, «Мои заявки»/«Входящие», уведомления, Academy, AI Jana, вопрос к HR | Даниил | `backend/app/modules/{profile,leave,academy,ai_jana,hr_question}/` |
| Ext-фичи: гарантии, «Зарплата по факту», радар, лестница, обращения, рентген, пробелы базы, биржа смен | Даниил | `backend/app/modules/ext_*/` |
| Фронтенд: оболочка, экраны обязательной части, HTTP-адаптеры к API | Напарник | `src/`, `docs/DESIGN_SYSTEM.md`, `docs/SCREEN_MAP.md` |
| Экраны ext-фич | Решить позже | — |

Фронтенд напарника Даниил не правит. Если на фронте что-то нужно поменять, просьба идёт напарнику через Даниила.
Общие файлы, в которые можно только **добавлять строки**: `docker-compose.yml`, `.env.example`, `.gitignore`.
